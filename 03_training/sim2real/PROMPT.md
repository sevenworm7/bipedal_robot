# 角色與目標
你是一位腿式機器人 sim-to-real 工程師。任務是以 `03_training` 訓練出的行走策略為起點，
在 Isaac Sim / Isaac Lab 中加入「實機會遇到、但目前模擬沒有」的各種變化，訓練出一個**能直接部署到實體
robot v1** 的行走策略：只使用實機量得到的觀測、能容忍伺服延遲與參數誤差、能在不平整與摩擦不一的地面上行走、
受到推擠時能恢復，而且步態不能只有單一模式。

# 背景
- 機器人：`custom_biped` v1（tag `robot-v1`，已凍結）；0.696 kg；每腿 4 DOF ＋ 2 DOF 尾巴；10 顆 Feetech HD-1910-C001；
  感測器只有 IMU（角速度、姿態）與伺服回讀的關節角。之後會 3D 列印並在真實地面測試。
- 起點：`03_training` 的最終蒸餾模型（`outputs/robot_v1/03_training/pipeline/iter3_distill_20261001_132024/model.pt`），
  在平地、理想馬達、輕推擠下成功率 99%、跌倒 1%、推擠測試 99%。
- 已知的落差（2026-10-06 分析）：
  1. **觀測**：目前的 44 維觀測包含 base 線速度，實機量不到；方向誤差在實機上來自會漂移的 IMU yaw。
  2. **致動器**：模擬用 DCMotor（kp 8、kd 0.3、無延遲）；實機伺服有內部 PID、指令延遲（約 6 ms ＋ 匯流排輪詢）、位置量化與背隙，參數未實測。
  3. **環境**：只訓練過平地、固定摩擦 1.0、質量為估計值（列印件以等效密度推算）、推擠 0.1 m/s。
  4. **步態單一**（使用者 2026-10-06 指出）：老師只有一組 CEM 參數，BC／PPO 又被「步態時鐘」獎勵鎖在固定的離地相位（0.05–0.50），
     抬腳高度、步寬、尾巴擺幅幾乎固定；遇到滑動、延遲或凹凸時，策略沒有其他步態可以切換，很可能在實機上直接失效。

# 需求（依序實作）

## 階段一：模擬環境的擴充（不可覆蓋舊場景）
1. 在 `shared/env` 加入以下功能，**全部預設關閉**；關閉時的行為必須和 03 完全相同（以固定評估集重跑 03 的最終模型，數字必須一致）：
   - 動作延遲（每個 episode 隨機延遲 0–N 個控制步，可選擇在 episode 中跳動）
   - 致動器參數隨機化（kp、kd、扭矩上限、關節摩擦、armature）
   - 質量、重心、腳底摩擦係數隨機化
   - 不規則地形（隨機高度場、小凸起、緩坡），含依表現升降的 curriculum
   - 觀測雜訊與偏差（IMU 角速度、重力方向、yaw 漂移、關節角）
   - 推擠強化（大小、方向、間隔可設定）
2. **場景版本控制**：每一組環境設定是一個具名、帶版本的「場景」（例如 `flat_v1` ＝ 03 使用的平地、`dr_v1`、`rough_v1`）。
   場景一旦被正式 run 使用就凍結，不可修改；要改就新增 `_v2`。每個 run 的 config 記錄場景名稱與 git commit。

## 階段二：可部署的觀測介面
1. 新增介面版本（例如 `ObsLayoutV2`），舊的 44 維介面不動：
   - actor：只含實機量得到的量（IMU 角速度、重力方向、指令、步態相位或頻率、關節角與角速度、上一次動作）＋最近數步的歷史
   - critic：actor 的全部＋特權資訊（base 線速度、摩擦、地形高度、延遲量、外力）
2. 動作空間（10 維、`q = q_default + 0.25 × a`）與控制頻率（50 Hz）維持不變，除非實測證明需要調整。

## 階段三：步態多樣性
1. 讓策略學到不只一種步態，並能依情況調整，例如：
   - 指令範圍擴大：包含原地踏步／站立、加減速、啟動與停止的轉換
   - 步態參數（步頻、抬腳高度、步寬、尾巴擺幅）在訓練中有變化，並可作為指令或由策略自行調整
   - 放寬「步態時鐘」獎勵，讓策略可以為了平衡提早或延後落腳
2. 定義可量化的「步態多樣性／適應性」指標（例如：不同情境下步頻、離地時間、落腳位置的分布；擾動後的恢復時間）。

## 階段四：強健性訓練
1. 以 03 的最終模型初始化，在擴充後的環境中以 PPO ＋ curriculum 訓練「特權策略」（critic 看得到特權資訊）。
2. 以 rsl_rl 的 student-teacher 蒸餾，得到只使用實機可得觀測（含歷史）的 student 策略。
3. 每個階段保留 checkpoint、config（含場景版本）、TensorBoard log 與評估影片。

## 階段五：評估
1. 固定評估集分難度，每一種都用固定 seed，數字可跨階段比較：
   - `flat_v1`（無隨機化，和 03 直接比較）
   - 中等隨機化、困難隨機化（延遲、參數、摩擦）
   - 不規則地形
   - 推擠測試（多種強度）
2. 指標：跌倒率、平均行走距離、速度誤差、側向偏移、方向誤差、扭矩飽和比例、步態多樣性指標；影片格式依 `/eval-video`。
3. 部署前檢查：student 在所有難度下的表現、在最差參數組合下的表現、策略輸出的平滑度（實機伺服無法追上高頻抖動）。
