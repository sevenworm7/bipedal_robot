# deploy：實體機器人（實驗二，尚未開始）

把模擬中訓練好的策略（`control/sim2real` 的 student v5）放到 3D 列印的實體機器人上走起來。
**目前尚未取得任何器材，這一步還沒有開始**（2026-10-15）；拿到器材後再建立下列子資料夾與程式。
這裡的程式在實機（Pi Zero 2 W）上執行，**不可依賴 Isaac Lab**，只能使用 `core/`（介面、機器人定義、伺服對照）。

## 預定的步驟（草案，開始前會再和使用者確認）

| 步驟 | 預定子資料夾 | 內容 | 通過條件 |
|---|---|---|---|
| 1. 採購與試印 | — | 依 `hardware/robot_v1/reports/parts_bom.md` 備料、試印關鍵件、秤重、確認孔位與馬達轉向（`hardware/v2_backlog.md` #3、#4） | 實測密度回填 |
| 2. 單顆馬達台架測試 | `actuator_bench/` | 量測反應延遲、追隨能力、受力偏移、回讀電流，和模擬的馬達模型（kp、kd、延遲範圍 0–40 ms）比對 | 落在訓練的隨機化範圍內；否則回到 `control/sim2real` 微調 |
| 3. 組裝與校正 | `calibration/` | 零點、轉向（`SERVO_MAP`）、IMU 軸向；量總重與重心；站姿和模擬比對 | 校正檔 |
| 4. 控制程式 | `runtime/` | 在板上執行 student v5（輸出和 PyTorch 完全相同）、50 Hz 控制迴圈、開機站起、安全停止 | 迴圈延遲 < 40 ms |
| 5. 懸吊測試 | `field_tests/` | 吊起來、腳不著地，確認方向與步態；再加安全繩放到地上 | 方向正確、不抖動 |
| 6. 平地行走 | `field_tests/` | 正式走路，和模擬比較速度、直線度、步頻、馬達負載與溫度 | 直線走完 2 m |
| 7. 進階測試 | `field_tests/` | 凹凸地面、推擠、長時間溫升 | — |

步驟 2 之前的模擬準備（馬達負載分析、`stress_v3`）在 [`evaluation/`](../evaluation/README.md)。產出預定放在 `outputs/robot_v1/deploy/`。
