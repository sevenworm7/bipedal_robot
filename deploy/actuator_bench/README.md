# deploy/actuator_bench：單顆馬達台架測試（`deploy/README.md` 步驟 2）

在機器人上（腿懸空、有人扶著）一次只開**一顆**伺服的扭矩，量出 HD-1910 的實際響應，和模擬的馬達模型比對：

| 模擬設定（`hardware/robot_v2/params.yaml`、`simulation/env/scenarios.py`） | 值 |
|---|---|
| DCMotor kp／kd | 8 N·m/rad／0.3 N·m·s/rad |
| 扭矩上限（連續／堵轉） | 0.8／1.18 N·m |
| 速度上限 | 9.6 rad/s |
| 摩擦／反射慣量 | 0.016 N·m／0.0018 kg·m² |
| 訓練隨機化（中等） | 延遲 0–40 ms、kp／kd ×0.7–1.3、扭矩 ×0.8–1.2 |

實測落在隨機化範圍內 → 不需要重訓，可以收窄範圍（`docs/backlog.md` #10）；超出 → 回 `control/sim2real` 用新範圍微調。

## 執行

```powershell
# 先燒錄含 STEP／SWEEP 的韌體（2026-11-24 起的 build），機器人懸空、扶好
.venv_fw\Scripts\python.exe deploy\actuator_bench\run_bench.py --suite regdump
.venv_fw\Scripts\python.exe deploy\actuator_bench\run_bench.py --suite step  --joints left_knee left_hip_pitch [--dry-run]
.venv_fw\Scripts\python.exe deploy\actuator_bench\run_bench.py --suite sweep --joints left_knee
tools\isaacpy.cmd deploy\actuator_bench\analyze.py [session 資料夾]
```

`run_bench.py` 把指令交給 `deploy/host/robot_cli.py`，每個指令後面等它做完（測試中送任何字元都會中止）；取樣行 `BS ...` 只寫進 `console.log`，不印在畫面上。
`analyze.py` 用 Isaac Lab 的 Python（只用 numpy、matplotlib，不載入 Isaac），輸出到 `<session>/bench_analysis/`：`regdump.csv`、`step_metrics.csv`（死區時間、t50、上升時間、超越量、安定時間、穩態誤差、最大速度）、`sweep_bode.csv`（增益、相位落後、等效延遲）、`step_<joint>.png`、`bode.png`。

## `jog_analyze.py`：單顆 JOG 分析（2026-11-25 從 `deploy/host/` 移來）

```powershell
.venv_fw\Scripts\python.exe deploy\actuator_bench\jog_analyze.py [session 資料夾]   # 預設最新的 session
```

從 `console.log` 讀韌體 `JOG` 指令的 100 Hz 紀錄，算方向、靜止誤差、最大追隨誤差、延遲（最小平方擬合 0–200 ms）、速度暫存器和差分速度的比值。2026-11-23 的單顆 JOG（延遲 25–35 ms，`deploy/test_log.md`）用它分析。

### 2026-11-24：E1 左膝步階（`sessions/20261124_200735`）

腿懸空，左膝（ID 3）先以 20°/s 轉到站姿 34°，再跳 ±2／5／10／20°、各停 0.8 s（8 次、16 個邊緣，0 讀取失敗）。取樣間隔 3.2 ms（約 300 Hz，比預期 1 kHz 慢，瓶頸可能是 USB printf）。第一次執行時膝蓋垂在 −5°（範圍外），全部被安全檢查擋下 → 加上「先轉到站姿角度」後重跑。

| 步階 | 死區時間 | t50 | 上升 10→90% | 超越量 | 安定時間 | 穩態誤差 | 最大速度 |
|---|---|---|---|---|---|---|---|
| 2° | 13–16 ms | 22–25 ms | 19 ms | ≤ 9%（1–2 count 量化） | — | ≤ 0.26° | 約 100°/s |
| 5° | 9.5–13 ms | 19–22 ms | 16–19 ms | 0–18% | 32–117 ms | ≤ 0.18° | 236–264°/s |
| 10° | 9.5–13 ms | 22–25 ms | 22–25 ms | ≤ 3% | 35–38 ms | ≤ 0.26° | 368–410°/s |
| 20° | 12.7 ms | 32–35 ms | 35–38 ms | ≤ 2% | 51–57 ms | ≤ 0.35° | **514–556°/s** |

- 死區時間約 10–13 ms（取樣 ±3 ms），含寫入目標到看見移動；t50 約 22 ms（小步階）到 35 ms（20°）。模擬的延遲隨機化 0–40 ms 涵蓋這個範圍。
- 20° 步階的最大速度 514–556°/s = 9.0–9.7 rad/s，和模擬的速度上限 9.6 rad/s 一致（懸空，只帶小腿與腳）。
- 幾乎沒有超越量（≥ 10° 時 ≤ 3%），穩態誤差 ≤ 0.35°。

### 2026-11-24：E2 左膝掃頻（`sessions/20261124_200940`）

中心＝站姿 34°，振幅 5°、0.5→8 Hz 對數 chirp 20 s（完整，5535 筆，實際取樣約 3.7 ms）；第二次 10°、0.5→6 Hz 在 3.4 秒（約 0.8 Hz）時**整條匯流排失去回應** → 連續 5 次讀取失敗中止，關扭矩也沒有回應（之後 `SCAN` 10 顆正常、ID 3 扭矩已關）。中止前電壓 7.7–7.8 V、電流小、誤差 < 1°，不是供電問題，和 `docs/backlog.md` #23 的匯流排斷線相同（疑似接線接觸不良，腿擺動時拉扯）。

| 頻率 | 0.57 | 1.03 | 1.53 | 2.25 | 3.33 | 4.92 | 5.98 | 7.27 Hz |
|---|---|---|---|---|---|---|---|---|
| 增益（5°） | 0.985 | 0.988 | 0.992 | 0.998 | 1.014 | 1.035 | 1.054 | 1.054 |
| 相位落後 | 6.6° | 8.9° | 12.0° | 16.8° | 23.8° | 36.0° | 44.8° | 56.5° |
| 等效延遲 | 32 ms | 24 ms | 22 ms | 21 ms | 20 ms | 20 ms | 21 ms | 22 ms |

- 到 7 Hz 增益都在 0.98–1.05（6–7 Hz 有 +0.5 dB 的小共振），相位落後和頻率成正比 → **行為接近「純延遲約 20–22 ms」**，低頻時略大（靜摩擦／不靈敏區）。步態頻率 1–1.6 Hz 時落後 9–12°、約 22 ms。10° 振幅的前段（0.57–0.81 Hz）結果相同（延遲 21–25 ms）。
- 量到的延遲含「寫入目標 → 讀回位置」的匯流排時間；實際閉迴路還要加上 50 Hz 週期與讀取全部 10 顆（約 6 ms）。模擬的 0–40 ms 隨機化涵蓋這個值。
